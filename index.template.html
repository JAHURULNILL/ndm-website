Up to 32 connections. NDM writes 1 MiB blocks to their final positions and journals progress as it happens. No temporary part files, no merge pass for a regular download.

Tools for the parts around a transfer.

Browser handoff, speed controls, queues, and video are there when you need them—not spread across a wall of features.

A

Refresh links, not files

If a signed download URL expires, attach a fresh address to its existing entry. Finished files are never overwritten.

B

Bring the browser along

The optional Chrome and Firefox extension hands browser downloads to NDM, including the link's cookies with that entry. Or paste a URL or drop a file onto the basket.

C

Keep control of the rest

Set per-file or global speed limits, add a quota, schedule named queues, grab linked files from a page, and route downloads into categories. Self-updates verify their SHA-256 before installing.

Video downloads in the desktop app

NDM tries stream data already loaded by the browser, then falls back to yt-dlp for pasted links and pages that expose no usable stream. It prefers H.264 and MP4; ffmpeg merges split picture and sound where needed. The Windows installer downloads video components when first used, while the Linux portable bundle includes them.

Video links are handled by the NDM app, not by this website. The sample picker formerly shown here used scripted example data; it was not a live downloader.

What changed in release 2.3.1
  1. Video downloads started from the browser now try the page's loaded stream data first; yt-dlp remains the fallback for pasted links and pages without usable stream data.
  2. The video picker reuses the probe it already performed, avoiding a second probe before a download starts.
  3. If a video stream stalls, NDM refreshes its address and resumes from the byte reached instead of starting over.
  4. Pause and resume work in every state, including while video is connecting; transfer rate and time remaining stay live while data moves.
  5. Facebook picker requests stop after 20 seconds, feed links are normalized, and filenames use the post text; Facebook's instant page-data picker is still being finished.
  6. Entries that cannot connect can still be removed from the list. A real deletion failure and a full disk now produce clear messages instead of silent retries.
  7. The browser extension's file dialog now uses the same file-name, folder, size, resume-support and action layout as the app's video picker.
  8. Drawn icons now cover the toolbar, menus and file rows; focus rings and button states are clearer. Dark Theme and Categories Sidebar switches work and are remembered.
  9. Updater downloads keep their real filenames, and the completion dialog fits inside the screen.

The release was tested with the shipped Debian package, browser-extension handoff, a Debian ISO checked against its published SHA-256, pause/resume, the live update feed, CI builds, and a silent Windows setup install-and-launch check. The release notes also record that Windows list sorting and its glass download card were still to come, and that the Windows toolbar retained text buttons.

A few useful answers.

Details about the app, not just the download.

Is NDM free?

Yes. NDM is free and open source under MIT OR Apache-2.0. There is no paid tier, account, or feature locked behind sign-in.

Which systems are supported?

Windows 7 SP1, 8, 8.1, 10, and 11 in 32-bit and 64-bit. The universal installer selects the matching build. Linux support is for x86-64 Debian-family distributions, through the .deb or portable tarball.

What information leaves my machine?

Your downloads go to the servers you choose. NDM checks its release feed and sends one anonymous install-count request with no identifier attached. There is no telemetry and no sign-in.
