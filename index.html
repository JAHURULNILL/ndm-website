Good to know

Requirements

  • Windows 10 or 11 (64-bit) — installer or portable
  • Ubuntu, Zorin OS, Linux Mint or any Debian-based distro (x86-64; ARM64 supported for the video engine)
  • WebKitGTK 4.1 and GTK 3 — installed automatically as dependencies
  • ffmpeg — also handled automatically by the package
  • Internet on first launch for the one-time video-engine setup (~83 MB, in the background)

Windows?

Fully supported since 2.0 — a per-user installer (no admin rights needed) and a portable ZIP, with the same features, the same browser extension, and the same one-click self-update as Linux.

Is NDM really free?

Yes — free and open source, no ads, no accounts, no tracking. The app sends exactly one anonymous install ping so the developer can count installations; nothing else ever leaves your machine.

How does the browser catch work?

The extension notices downloads and video pages in your browser and hands them to the app through a small native bridge — the same approach IDM uses. Cookies are captured only for the link you clicked, stored locally on your machine, and deleted together with the entry.

Can it resume a failed download?

Yes — where the server supports range requests (most do), NDM resumes from the exact byte, even after a restart, and even for login-gated files whose session it saved.

Why is the Linux package only about 5 MB?

The app itself is small and native (Rust + Tauri). On Linux the video engine — yt-dlp and deno — is fetched once, in the background, and verified against pinned SHA-256 hashes before it can run. The Windows setup (101 MB) goes the other way and bundles everything, so it works fully offline from the first launch.

How do updates work?

NDM checks the release feed on launch. A normal update is one click. If a release is marked mandatory, older versions pause new downloads until updated, so important fixes reach everyone.
