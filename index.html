Check what you received

Each file’s SHA-256 is printed beside it, exactly as published with the release. Compare the hash of the file you received before you run it:

Get-FileHash .\NDM_2.1.1_x64-setup.exe -Algorithm SHA256
sha256sum NDM_2.1.1_amd64.deb

The same release also carries NDM_2.1.1_Linux_Portable.tar.xz (120 MB), a portable build for other Linux distributions with the video components bundled. It is attached to the release; it is not one of the feed’s four files.

What changed in 2.1.1

  • The download list can no longer scramble itself. With a finished download in the list while another was added and one was deleted, rows could end up showing one download’s name over another’s state — and a later delete could remove the wrong thing on screen. Rows now keep their identity through every add, finish and delete.
  • A failed add leaves nothing behind. A dead link — a 404, a gone file — could leave a phantom row that existed only on screen: not in the journal, not on disk, impossible to resume. A failed add now fails cleanly: an honest message, and no row.
  • A video file offered as a video stays a video. A browser handing NDM a direct link to a video file could see it taken down the plain-file path; direct-media downloads now keep their video handling end to end.
  • The progress dialog tells the truth after an error. It could keep showing figures from before the failure; now it shows exactly what is actually on disk — the real downloaded amount, the real percentage, and whether resume can honestly work — and resuming from that point finishes byte-identical.
  • An unreachable host fails like it should. Instead of sitting in a probing state far too long, it now fails cleanly inside a clear bound, with the entry properly recorded and a reason you can read.
  • Smaller honesty fixes, same pass. The progress dialog’s connection table now shows every row — before, rows past the eighth could silently go missing — paused downloads are labelled “Paused”, and error messages are written in plain language: what happened, and what you can do about it.
  • A quieter codebase. With the native interface proven, the retired WebView-era code has been removed for good — about 58,000 lines of the old shell, the old web UI and their supporting scripts. Behaviour is unchanged; it is the same app, minus the scaffolding it no longer needs.

A note on proof: every fix above was verified the way it was found — by driving the finished app through the failing sequence and watching it behave, including error cases staged against a local server, killed mid-download and resumed to a byte-identical finish. The Windows build passed its install-and-launch checks in CI, as it did for 2.1.0.

First, take the file for your system.

Setup, portable, .deb and the extension are the four files above, each published with its SHA-256.

Then add a link, from anywhere.

Paste a URL, drop a file on the basket, or let the browser extension hand the download over, with that link’s cookies attached to the entry.

NDM pulls it down in parallel.

Up to 32 connections write 1 MiB blocks at their final offsets, and a journal records the progress as it happens.

At 100%, it is whole.

No part files and no merge pass, because the file was written in place. Stop it at any point and it resumes from the recorded byte; a finished file is never overwritten.

An engine that expects interruption.

Resume is a journal, not a hope

Progress is written to downloads.json as it happens. Restart the app or the machine, or let a signed link expire: the entry keeps its bytes, and Refresh Address attaches a fresh link to the same entry.

A limiter on each download

Set a rate for one file while it runs, or a global cap with a quota in megabytes over 1 to 168 hours. The change applies mid-flight, not at the next start.

Queues that keep hours

Named queues carry their own concurrency caps and start and stop times. When a queue runs dry it can close the app, or shut the machine down.

Whole sites in one go

Site Grabber walks a page and takes every linked file of the types you choose. Categories then route each finished file into its folder by extension, and the drop basket takes drags from anywhere.

Updates that check themselves

NDM reads its own release feed, verifies the SHA-256 of an update before installing it, and honours the feed’s minimum supported version — the 2.0.10 feed used it to require that update.

Questions

Is NDM really free?

Yes, and open source. There is no paid tier, no account and nothing locked behind one. The four files in the release above are the whole product.

Why is the installer only 4.30 MB?

It is the app alone: one Rust engine serves both platforms, and the app carries its C runtime with it. The video components (yt-dlp, deno and ffmpeg) are downloaded once, in the background, the first time a video is resolved, and each is checked against a SHA-256 pinned in the app before it may run.

Which systems does it run on?

Windows 7 SP1, 8, 8.1, 10 and 11, 64-bit. On 7, 8 and 8.1 the installer also provisions Microsoft’s pinned WebView2 109 runtime during setup, hash-checked, with nothing to click. On Linux, a Debian-family distribution on x86-64 (Debian, Ubuntu, Zorin OS, Linux Mint and derivatives), through the .deb or the portable tarball.

What leaves my machine?

Your downloads, from the servers you pick. An update check against the release feed. And one anonymous install count, an empty request with no identifier attached. There is no telemetry and no sign-in.

A download stopped at 99%. Is it lost?

No. Progress lives in the journal, not in temporary part files, because there are no part files. Resume continues from the recorded byte. If the link itself has expired, Refresh Address attaches a fresh signed link to the same entry, and an interrupted merge restores as paused and is verified before it can count as finished.

Do I need the browser extension?

No. Paste a link, or drag one onto the drop basket. The extension, for Chrome and Firefox, only removes the copy and paste: it sends the browser’s downloads to the app, carrying the cookies for that link, which are stored with that entry only.
